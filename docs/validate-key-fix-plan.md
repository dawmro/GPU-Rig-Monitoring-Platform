# Fix validate_key Design Flaw: Prefix Index (Nullable, No Boolean Flag)

## Problem Statement

**Current implementation** (`accounts/models.py:64-76`) performs a linear scan of all active API keys with Argon2 verification per candidate:

```python
@classmethod
def validate_key(cls, plaintext: str):
    for key_obj in cls.objects.filter(is_active=True).select_related('user'):
        ph = PasswordHasher()
        try:
            if ph.verify(key_obj.key_hash, plaintext):
                key_obj.last_used_at = timezone.now()
                key_obj.save(update_fields=['last_used_at'])
                return key_obj, None
        except (VerifyMismatchError, Exception):
            continue
    return None, "Invalid or revoked API key"
```

### Scaling Failure

| Active Keys | Avg SELECTs | Avg Argon2 | CPU @ 50ms/Argon2 (4 workers) |
|-------------|-------------|------------|-------------------------------|
| 20 | 10 | 10 | 16% |
| 100 | 50 | 50 | 83% |
| 500 | 250 | 250 | 417% (stall) |
| 1000 | 500 | 500 | 833% (complete stall) |

At 1000 rigs × 1 req/min = 16.7 req/sec sustained → **server stalls on authentication alone**.

---

## Solution: Nullable Prefix Index (Single Field)

### Core Design

1. **Add `key_prefix` field** — first 16 chars of plaintext key, `null=True`, `db_index=True`
2. **`NULL` = legacy key** (not yet migrated)
3. **Non-NULL = migrated key** (fast path available)
4. **Two-phase lookup**:
   - Phase 1: `WHERE is_active=True AND key_prefix='...'` (indexed, O(1))
   - Phase 2: `WHERE is_active=True AND key_prefix IS NULL` (indexed, shrinks over time)
5. **Automatic migration** — on first successful auth of legacy key, populate `key_prefix`
6. **No boolean flag needed** — prefix NULL-ness IS the migration state

### Security

- Prefix = 16 chars × 6 bits/char = 96 bits of 288-bit key (33% entropy exposure)
- Full key still verified via Argon2id (memory=65536, time=3, parallelism=4)
- Legacy keys store `NULL` → **zero entropy loss** for existing deployed rigs
- Collision probability ~10⁻¹⁹ with 1000 keys (64-bit effective space)
- Argon2 remains **final authentication check** — prefix is only a lookup hint

### Step 2: Update ApiKey Model (Complete Replacement)

**File:** `gpu_monitor/accounts/models.py`

```python
import secrets
import uuid

from argon2 import PasswordHasher
from argon2.exceptions import VerifyMismatchError

from django.contrib.auth.models import AbstractUser
from django.db import models
from django.utils import timezone


class User(AbstractUser):
    email = models.EmailField(unique=True)
    is_admin = models.BooleanField(default=False)
    electricity_rate_kwh = models.DecimalField(
        max_digits=6,
        decimal_places=4,
        default=0.3300,
        help_text="Electricity cost per kWh",
    )
    USERNAME_FIELD = "email"
    REQUIRED_FIELDS = ["username"]

    def __str__(self):
        return self.email

    def get_safe_identifier(self):
        return f"{self.id:08x}"


class ApiKey(models.Model):
    # ------------------------------------------------------------------
    # Configuration
    # ------------------------------------------------------------------
    KEY_PREFIX_LENGTH = 16
    ARGON2_MEMORY_COST = 65536
    ARGON2_TIME_COST = 3
    ARGON2_PARALLELISM = 4

    # ------------------------------------------------------------------
    # Database fields
    # ------------------------------------------------------------------
    id = models.UUIDField(
        primary_key=True,
        default=uuid.uuid4,
        editable=False,
    )
    user = models.ForeignKey(
        User,
        on_delete=models.CASCADE,
        related_name="api_keys",
    )
    name = models.CharField(max_length=255)
    base_name = models.CharField(max_length=255, blank=True)

    # The complete API key is NEVER stored here.
    # This remains an Argon2 password-style hash.
    key_hash = models.CharField(max_length=255)

    # NEW FIELD: NULL = legacy, non-NULL = migrated
    key_prefix = models.CharField(
        max_length=KEY_PREFIX_LENGTH,
        null=True,
        blank=True,
        db_index=True,
    )

    is_active = models.BooleanField(default=True)
    created_at = models.DateTimeField(auto_now_add=True)
    last_used_at = models.DateTimeField(null=True, blank=True)
    revoked_at = models.DateTimeField(null=True, blank=True)
    transfer_count = models.PositiveIntegerField(default=0)

    class Meta:
        db_table = "accounts_apikey"
        unique_together = ("user", "name")

    def __str__(self):
        return f"{self.name} ({self.user})"

    # ------------------------------------------------------------------
    # Password hashing (single source of truth for parameters)
    # ------------------------------------------------------------------
    @classmethod
    def get_password_hasher(cls):
        """Return the Argon2 PasswordHasher used for API keys."""
        return PasswordHasher(
            memory_cost=cls.ARGON2_MEMORY_COST,
            time_cost=cls.ARGON2_TIME_COST,
            parallelism=cls.ARGON2_PARALLELISM,
        )

    @classmethod
    def hash_key(cls, plaintext: str) -> str:
        """Hash a complete API key with Argon2."""
        ph = cls.get_password_hasher()
        return ph.hash(plaintext)

    @classmethod
    def get_key_prefix(cls, plaintext: str) -> str:
        """Return the non-secret lookup prefix (first 16 chars)."""
        return plaintext[:cls.KEY_PREFIX_LENGTH]

    # ------------------------------------------------------------------
    # API key generation
    # ------------------------------------------------------------------
    @classmethod
    def generate_key(cls) -> str:
        """Generate a cryptographically random API key."""
        return secrets.token_urlsafe(32)

    @classmethod
    def create_key(cls, *, user, name, base_name=""):
        """
        Create a new API key.
        Returns: (api_key_object, plaintext_key)
        The plaintext key should be shown/stored by the client only.
        """
        plaintext = cls.generate_key()
        api_key = cls.objects.create(
            user=user,
            name=name,
            base_name=base_name,
            key_hash=cls.hash_key(plaintext),
            key_prefix=cls.get_key_prefix(plaintext),
        )
        return api_key, plaintext

    # ------------------------------------------------------------------
    # Verification helpers
    # ------------------------------------------------------------------
    @classmethod
    def _verify_candidate(cls, key_obj, plaintext, ph):
        """
        Verify one candidate API key.
        Returns: True (valid) / False (invalid).
        Only VerifyMismatchError is treated as auth failure.
        """
        try:
            return ph.verify(key_obj.key_hash, plaintext)
        except VerifyMismatchError:
            return False

    # ------------------------------------------------------------------
    # Fast authentication path (migrated keys)
    # ------------------------------------------------------------------
    @classmethod
    def _validate_using_prefix(cls, plaintext, prefix, ph):
        """
        Fast path for keys that already have key_prefix populated.
        Normally produces zero or one candidates.
        Multiple candidates handled correctly (prefix is only a hint).
        """
        candidates = (
            cls.objects
            .filter(is_active=True, key_prefix=prefix)
            .select_related("user")
        )
        for key_obj in candidates:
            if cls._verify_candidate(key_obj, plaintext, ph):
                key_obj.last_used_at = timezone.now()
                key_obj.save(update_fields=["last_used_at"])
                return key_obj
        return None

    # ------------------------------------------------------------------
    # Legacy authentication path + automatic migration
    # ------------------------------------------------------------------
    @classmethod
    def _validate_legacy_key(cls, plaintext, prefix, ph):
        """
        Authenticate keys that do not yet have a prefix.
        Once a legacy key successfully verifies, populate key_prefix.
        The API key itself does NOT change.
        """
        candidates = (
            cls.objects
            .filter(is_active=True, key_prefix__isnull=True)
            .select_related("user")
        )
        for key_obj in candidates:
            if not cls._verify_candidate(key_obj, plaintext, ph):
                continue

            # Successful legacy authentication → migrate
            key_obj.key_prefix = prefix
            key_obj.last_used_at = timezone.now()
            key_obj.save(update_fields=["key_prefix", "last_used_at"])
            return key_obj
        return None

    # ------------------------------------------------------------------
    # Public authentication method
    # ------------------------------------------------------------------
    @classmethod
    def validate_key(cls, plaintext: str):
        """
        Validate an API key.
        Strategy:
        1. Calculate prefix (first 16 chars).
        2. Search migrated keys using indexed key_prefix.
        3. Argon2 verification only for matching candidates.
        4. If not found, fall back to legacy keys (key_prefix IS NULL).
        5. When a legacy key succeeds, automatically populate its
           key_prefix so future requests use the fast path.
        Existing API keys remain unchanged.
        """
        if not plaintext:
            return None, "Invalid or revoked API key"

        prefix = cls.get_key_prefix(plaintext)
        ph = cls.get_password_hasher()  # Create ONCE per request

        # FAST PATH: migrated keys
        key_obj = cls._validate_using_prefix(
            plaintext=plaintext,
            prefix=prefix,
            ph=ph,
        )
        if key_obj is not None:
            return key_obj, None

        # LEGACY FALLBACK: keys without prefix
        key_obj = cls._validate_legacy_key(
            plaintext=plaintext,
            prefix=prefix,
            ph=ph,
        )
        if key_obj is not None:
            return key_obj, None

        return None, "Invalid or revoked API key"
```

## Query Plans

### Before (Current)
```sql
-- Full sequential scan
SELECT * FROM accounts_apikey WHERE is_active = TRUE;
-- Then N Argon2 verifies in Python
```

### After — Phase 1 (Migrated Keys)
```sql
-- Index seek on (key_prefix, is_active)
SELECT * FROM accounts_apikey
WHERE is_active = TRUE AND key_prefix = 'ABCDEF1234567890';
-- 0-1 rows → 1 Argon2 verify
```

### After — Phase 2 (Legacy Keys)
```sql
-- Index seek on (key_prefix, is_active) with IS NULL
SELECT * FROM accounts_apikey
WHERE is_active = TRUE AND key_prefix IS NULL;
-- Legacy rows only (shrinks over time) → 1 Argon2 verify
```

### After — Invalid Key (Post-Migration)
```sql
-- Phase 1: index miss (0 rows)
-- Phase 2: index seek on key_prefix IS NULL (0 rows if fully migrated)
-- 0 Argon2 verifies
```

## Future Enhancements (Post-Migration)

1. **Database cache for auth** (60s TTL) — eliminates Argon2 for repeated requests
2. **Redis throttle** — replaces LocMemCache for fleet-wide rate limiting
3. **Async Argon2 verify** — offload to thread pool for high concurrency
4. **Key rotation endpoint** — issue new key, revoke old, seamless migration
5. **Throttle last_used_at updates** — only update if >5 min old:
   ```python
   if (
       key_obj.last_used_at is None
       or key_obj.last_used_at < timezone.now() - timedelta(minutes=5)
   ):
       key_obj.last_used_at = timezone.now()
       key_obj.save(update_fields=["last_used_at"])
   ```

These are **optional** — the nullable prefix index solves the design flaw completely.

## Design Decisions (from external review)

The following decisions shaped this implementation:

| # | Decision | Rationale |
|---|----------|-----------|
| 1 | **Do not modify existing API-key strings** | No credential rotation; clients unchanged |
| 2 | **Keep Argon2** | Don't change crypto + performance simultaneously |
| 3 | **Argon2 cannot be used for lookup** | Salted hashes; plaintext unrecoverable |
| 4 | **Store only a prefix** | Not plaintext; prefix = candidate selection only |
| 5 | **Argon2 = authentication, prefix = lookup** | Clean separation of responsibilities |
| 6 | **Nullable prefix = migration state** | `NULL`=legacy, non-NULL=migrated; single source of truth |
| 7 | **Auto-migrate on successful auth** | Lazy migration without client changes |
| 8 | **Migrate ONLY after Argon2 success** | Prevents attacker populating metadata |
| 9 | **Keep legacy fallback** | `key_prefix IS NULL` for backward compatibility |
| 10 | **Exclude migrated from legacy scan** | `key_prefix__isnull=True` shrinks search space |
| 11 | **Generate prefix for new keys** | Fast path from first request |
| 12 | **Use 16-char prefix** | 64-bit effective space; collision headroom |
| 13 | **Prefix collisions acceptable** | Argon2 resolves; affects performance not correctness |
| 14 | **One PasswordHasher per request** | Avoids unnecessary object creation |
| 15 | **Catch only VerifyMismatchError** | No broad Exception swallowing |

## Architecture Flow

```
                     API REQUEST
                          │
                          ▼
                    plaintext key
                          │
                          ▼
                 calculate 16-char prefix
                          │
                          ▼
              ┌─────────────────────────┐
              │ indexed key_prefix      │
              │ + is_active             │
              └────────────┬────────────┘
                           │
                    candidate found?
                     /             \
                   YES              NO
                    │                │
                    ▼                ▼
             Argon2 verify      legacy lookup
                    │                │
                 success             │
                    │             Argon2 verify
                    │                │
                    │             success
                    │                │
                    │          save key_prefix
                    │                │
                    └───────┬────────┘
                            ▼
                       authenticated
```

**Critical property:** The credential itself never changes.

| Stage | Behavior |
|-------|----------|
| Before deployment | Works (legacy path) |
| First use | Works + prefix added |
| Subsequent use | Works via fast lookup |
| Client sees | **Absolutely no change** |

## Limitations

> There is no way to make the very first authentication of an unknown legacy key O(1) using only the data you currently have.

You have Argon2 hashes A, B, C... and receive a plaintext key. There is no searchable relationship between the plaintext and those Argon2 hashes. Therefore the first successful authentication of an unmigrated key necessarily requires the legacy search.

After that:
```
legacy → successful verification → prefix stored → fast authentication forever
```
unless the key is revoked/deleted.

This is the unavoidable trade-off that preserves every existing credential.
