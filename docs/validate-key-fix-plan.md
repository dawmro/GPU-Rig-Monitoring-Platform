# Fix validate_key Design Flaw: Prefix Index + Boolean Flag

## Problem Statement

**Current implementation** (`accounts/models.py:64-76`) performs a linear scan of all active API keys with Argon2 verification per candidate:

```python
@classmethod
def validate_key(cls, plaintext: str):
    for key_obj in cls.objects.filter(is_active=True).select_related('user'):
        ph = PasswordHasher()
        try:
            if ph.verify(key_obj.key_hash, plaintext):
                key_obj.last_used_at = timezone.now()
                key_obj.save(update_fields=['last_used_at'])
                return key_obj, None
        except (VerifyMismatchError, Exception):
            continue
    return None, "Invalid or revoked API key"
```

### Scaling Failure

| Active Keys | Avg SELECTs | Avg Argon2 | CPU @ 50ms/Argon2 (4 workers) |
|-------------|-------------|------------|-------------------------------|
| 20 | 10 | 10 | 16% |
| 100 | 50 | 50 | 83% |
| 500 | 250 | 250 | 417% (stall) |
| 1000 | 500 | 500 | 833% (complete stall) |

At 1000 rigs × 1 req/min = 16.7 req/sec sustained → **server stalls on authentication alone**.

---

## Solution: Prefix Index + Boolean Flag

### Core Idea

1. **Store first 8 characters of plaintext key** as `key_prefix` (indexed)
2. **Add `has_prefix` boolean flag** (indexed) to distinguish migrated vs legacy keys
3. **Two-phase lookup**: Phase 1 uses prefix index (O(1)), Phase 2 uses boolean index for legacy (O(1))
4. **Legacy keys backfill on first successful auth** → gradually migrate to Phase 1

### Security

- Prefix = 8 chars × 6 bits/char = 48 bits of 288-bit key
- Full key still verified via Argon2id (memory=65536, time=3, parallelism=4)
- Legacy keys (existing deployed rigs) store `NULL`/`False` → zero entropy loss
- Collision probability ~10⁻¹⁰ with 1000 keys

```python
# Add these fields to ApiKey class (after key_hash field, ~line 38):
class ApiKey(models.Model):
    id = models.UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
    user = models.ForeignKey(User, on_delete=models.CASCADE, related_name='api_keys')
    name = models.CharField(max_length=255)
    base_name = models.CharField(max_length=255, blank=True)
    key_hash = models.CharField(max_length=255)
    key_prefix = models.CharField(max_length=8, null=True, blank=True)      # NEW
    has_prefix = models.BooleanField(default=False, db_index=True)          # NEW
    is_active = models.BooleanField(default=True)
    created_at = models.DateTimeField(auto_now_add=True)
    last_used_at = models.DateTimeField(null=True, blank=True)
    revoked_at = models.DateTimeField(null=True, blank=True)
    transfer_count = models.PositiveIntegerField(default=0)

    class Meta:
        unique_together = ('user', 'name')
        db_table = 'accounts_apikey'

    # ... existing methods (hash_key, verify_key) ...

    @classmethod
    def validate_key(cls, plaintext: str):
        """
        Two-phase API key validation:
        Phase 1: Fast path - keys with prefix (indexed lookup)
        Phase 2: Legacy fallback - keys without prefix (indexed boolean)
        """
        from django.utils import timezone
        from argon2 import PasswordHasher
        from argon2.exceptions import VerifyMismatchError

        prefix = plaintext[:8]
        ph = PasswordHasher()

        # Phase 1: Keys with prefix (uses has_prefix=True + key_prefix index)
        for key_obj in cls.objects.filter(
            is_active=True, has_prefix=True, key_prefix=prefix
        ).select_related('user'):
            try:
                if ph.verify(key_obj.key_hash, plaintext):
                    key_obj.last_used_at = timezone.now()
                    key_obj.save(update_fields=['last_used_at'])
                    return key_obj, None
            except (VerifyMismatchError, Exception):
                continue

        # Phase 2: Legacy keys without prefix (uses has_prefix=False index)
        for key_obj in cls.objects.filter(
            is_active=True, has_prefix=False
        ).select_related('user'):
            try:
                if ph.verify(key_obj.key_hash, plaintext):
                    # Backfill prefix for next time (gradual migration)
                    key_obj.key_prefix = prefix
                    key_obj.has_prefix = True
                    key_obj.last_used_at = timezone.now()
                    key_obj.save(update_fields=['key_prefix', 'has_prefix', 'last_used_at'])
                    return key_obj, None
            except (VerifyMismatchError, Exception):
                continue

        return None, "Invalid or revoked API key"
```

## Query Plan Comparison

### Before (Current)
```sql
-- Full sequential scan of all active keys
SELECT * FROM accounts_apikey 
WHERE is_active = TRUE;
-- Then 20 Argon2 verifies in Python
```

### After (Phase 1 - New/Migrated Keys)
```sql
-- Index seek on (has_prefix, key_prefix, is_active)
SELECT * FROM accounts_apikey 
WHERE is_active = TRUE 
  AND has_prefix = TRUE 
  AND key_prefix = 'sk_live_a';
-- 1 row → 1 Argon2 verify
```

### After (Phase 2 - Legacy Keys)
```sql
-- Index seek on (has_prefix, is_active)
SELECT * FROM accounts_apikey 
WHERE is_active = TRUE 
  AND has_prefix = FALSE;
-- Legacy rows only (shrinks over time) → 1 Argon2 verify
```

### After (Invalid Key)
```sql
-- Phase 1: index miss (0 rows)
-- Phase 2: index seek on has_prefix=False (legacy count, shrinks to 0)
-- 0 Argon2 verifies
```

## Future Enhancements (Post-Migration)
